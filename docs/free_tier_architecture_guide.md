# നാട്ടിലെ ആപ്പ് (Ente Naadu) – പരമാവധി സൗജന്യമായി സെറ്റ് ചെയ്യാനുള്ള ഗൈഡ്

> **ശ്രദ്ധിക്കുക:** വില, പരിധി വിവരങ്ങൾ 2026 ഒക്ടോബറിൽ പരിശോധിച്ചതാണ്. ഇവ മാറാം, അതിനാൽ ഉപയോഗിക്കുന്നതിന് മുൻപ് ഓരോ സേവനത്തിൻ്റെയും ഔദ്യോഗിക പ്രൈസിംഗ് പേജ് പരിശോധിക്കുക.

---

## 1. ലക്ഷ്യവും പ്രധാന തത്വവും

പ്രോജക്റ്റ് തുടങ്ങാനും നാട്ടിൽ പരീക്ഷിക്കാനും പണം ചെലവാക്കാതെ കഴിയണം. ഇതിന് 3 തത്വങ്ങൾ പാലിക്കാം:

1. **ഒരു ബാക്കെൻഡ്, മൂന്ന് പ്ലാറ്റ്ഫോം:** Django ബാക്കെൻഡ് ഒന്ന് മാത്രം; വെബ്സൈറ്റും ആൻഡ്രോയിഡും iOS-ഉം അതിനെ ഉപയോഗിക്കും.
2. **ഫ്രീ ടിയർ ഉള്ള സേവനങ്ങൾ മാത്രം:** സ്വന്തമായി സെർവർ വാങ്ങുകയോ കോൾ/ചാറ്റ് സെർവർ ഉണ്ടാക്കുകയോ ചെയ്യരുത്.
3. **ചെലവ് വരുന്ന ഫീച്ചറുകൾ പിന്നീട്:** SMS OTP, ഓൺലൈൻ പേയ്മെൻ്റ്, iOS സ്റ്റോർ എന്നിവ ഉപയോക്താക്കൾ ആയ ശേഷം മതി.

## 3. ചെലവ് വരാൻ സാധ്യതയുള്ള 4 കാര്യങ്ങളും ഒഴിവാക്കാനുള്ള വഴിയും

### 3.1 SMS OTP ലോഗിൻ
- Firebase-ൽ ഫോൺ OTP ഉപയോഗിക്കാൻ പണമടയ്ക്കുന്ന (Blaze) പ്ലാൻ വേണം. ഓരോ SMS-നും പണം ഈടാക്കും (ദിവസം ആദ്യത്തെ 10 SMS സൗജന്യം; ഇന്ത്യയിലെ നിരക്ക് ഏകദേശം $0.01 മുതൽ $0.07 വരെ).
- **ഒഴിവാക്കാൻ:** ഫോൺ നമ്പറും പാസ്‌വേഡും ഉപയോഗിച്ച് Django-യുടെ സ്വന്തം ലോഗിൻ ഉപയോഗിക്കുക, അല്ലെങ്കിൽ Google Sign-In (50,000 മാസ ഉപയോക്താക്കൾ വരെ സൗജന്യം). പാസ്‌വേഡ് മറന്നാൽ അഡ്മിൻ റീസെറ്റ് ചെയ്യുന്ന രീതി തുടക്കത്തിൽ മതി. OTP പിന്നീട് ചേർക്കാം.

### 3.2 ഡാറ്റാബേസ് കാലഹരണപ്പെടൽ
- Render-ലെ സൗജന്യ Postgres ഡാറ്റാബേസ് 30 ദിവസം കഴിഞ്ഞാൽ കാലഹരണപ്പെടും, ഡാറ്റ നഷ്ടപ്പെടാം.
- **ഒഴിവാക്കാൻ:** ഡാറ്റാബേസിന് **Neon** (അല്ലെങ്കിൽ Supabase) ഉപയോഗിച്ച് Render-ൽ അതിൻ്റെ കണക്ഷൻ വിലാസം (`DATABASE_URL`) നൽകുക. ആഴ്ചയിൽ ഒരിക്കൽ ഡാറ്റ ബാക്കപ്പ് എടുക്കുക (Django-യിൽ `dumpdata` കമാൻഡ്).

### 3.3 സെർവർ ഉറങ്ങുന്ന പ്രശ്നം
- സൗജന്യ Render സർവീസ് 15 മിനിറ്റ് ഉപയോഗിക്കാതിരുന്നാൽ ഉറങ്ങും, അടുത്ത ഉപയോക്താവിന് ആപ്പ് തുറക്കാൻ 30–60 സെക്കൻഡ് എടുക്കും. നോട്ടിഫിക്കേഷനും ചാറ്റും ഈ സമയത്ത് വൈകാം.
- **ഒഴിവാക്കാൻ:** പരീക്ഷണ ഘട്ടത്തിൽ ഇത് സഹിക്കാം; ആളുകൾ ഉപയോഗിച്ചു തുടങ്ങുമ്പോൾ മാസം ഏകദേശം $7-ൻ്റെ പണമടച്ച ഇൻസ്റ്റൻസിലേക്ക് (Starter) മാറുക. ആപ്പിൽ "ലോഡ് ചെയ്യുന്നു / ഉണരുന്നു..." എന്ന ഇൻഡിക്കേറ്റർ നൽകുക.

### 3.4 കോൾ മിനിറ്റ് തീരുന്നത്
- Agora-യിൽ മാസം 10,000 മിനിറ്റ് സൗജന്യമാണ്. ബാക്കി മിനിറ്റുകൾ അടുത്ത മാസത്തേക്ക് കൈമാറില്ല.
- **ഒഴിവാക്കാൻ:** തുടക്കത്തിൽ വോയ്സ് കോൾ മാത്രം നൽകുക; കോൾ ദൈർഘ്യത്തിന് പരിധി വയ്ക്കുക; ഉപയോഗം കൂടിയാൽ കോൾ ഫീച്ചർ ഷോപ്പ്-ഉപയോക്തൃ കോളുകൾക്കോ അടുത്ത സുഹൃത്തുക്കൾക്കോ മാത്രമാക്കുക.

## 4. ഘട്ടം ഘട്ടമായുള്ള സെറ്റപ്പ് ക്രമം

1. **GitHub അക്കൗണ്ട്:** കോഡ് സൗജന്യമായി സൂക്ഷിക്കാനും Render-ലേക്ക് ഓട്ടോമാറ്റിക് ഡിപ്ലോയ് ചെയ്യാനും (private repository സൗജന്യം).
2. **Neon അക്കൗണ്ട്:** ഒരു Postgres പ്രോജക്റ്റ് ഉണ്ടാക്കി കണക്ഷൻ URL (`postgres://...`) എടുക്കുക.
3. **Django പ്രോജക്റ്റ്:** `DATABASE_URL` എൻവയോൺമെൻ്റ് വേരിയബിൾ വഴി ഡാറ്റാബേസ് ബന്ധിപ്പിക്കുക; `gunicorn`, `whitenoise` (static ഫയലുകൾക്ക്), `dj-database-url` എന്നിവ ഉപയോഗിക്കുക.
4. **Render അക്കൗണ്ട്:** GitHub repo ബന്ധിപ്പിച്ച് ഒരു സൗജന്യ Web Service ഉണ്ടാക്കുക; `DATABASE_URL`, `SECRET_KEY`, `DEBUG=False` എന്നിവ Environment-ൽ നൽകുക.
5. **Firebase പ്രോജക്റ്റ് (Spark പ്ലാൻ):** പുഷ് നോട്ടിഫിക്കേഷനായി മാത്രം ഉപയോഗിക്കുക; Blaze-ലേക്ക് മാറ്റരുത്.
6. **ഫോട്ടോ സ്റ്റോറേജ്:** Supabase Storage അല്ലെങ്കിൽ Cloudinary സൗജന്യ അക്കൗണ്ട് ബന്ധിപ്പിക്കുക (Render-ൻ്റെ ഡിസ്കിൽ ഫയൽ സൂക്ഷിക്കരുത്, സൗജന്യ സർവീസിൽ അത് റീസ്റ്റാർട്ടിൽ നഷ്ടപ്പെടും).
7. **Flutter ആപ്പ്:** `flutter_map` (OpenStreetMap), `firebase_messaging` എന്നിവ ഉപയോഗിക്കുക; API URL Render-ൻ്റെ വിലാസത്തിലേക്ക് നൽകുക.
8. **Android:** `flutter build apk` വഴി APK ഉണ്ടാക്കി WhatsApp/ഡ്രൈവ് ലിങ്ക് വഴി പരിചയക്കാർക്ക് നൽകി പരീക്ഷിക്കുക.
9. **iOS:** ഇപ്പോൾ പണം ചെലവാക്കാതെ വെബ്സൈറ്റ് ഫോണിൽ ഹോം സ്ക്രീനിൽ ചേർത്ത് ഉപയോഗിക്കാവുന്ന PWA ആക്കുക. ആപ്പിൽ ഉപയോക്താക്കൾ ഉറപ്പായപ്പോൾ Apple Developer അക്കൗണ്ട് എടുക്കുക.

## 7. സൗജന്യ പ്ലാനിൽ ശ്രദ്ധിക്കേണ്ട പ്രധാന മുൻകരുതലുകൾ

- **പരിധി കടന്നാൽ സേവനം നിൽക്കാം:** Firebase, Agora എന്നിവ സൗജന്യ പരിധി കഴിഞ്ഞാൽ തനിയെ ചാർജ് ചെയ്യാതിരിക്കാൻ സേവനം നിർത്തിയേക്കാം. ഉപയോഗം ഡാഷ്‌ബോർഡിൽ പരിശോധിക്കുക.
- **ഡാറ്റ ബാക്കപ്പ്:** സൗജന്യ സേവനങ്ങൾക്ക് ഉറപ്പുള്ള ബാക്കപ്പ് ലഭിക്കില്ല. ആഴ്ചയിൽ ഒരിക്കൽ ഡാറ്റ എക്സ്പോർട്ട് ചെയ്ത് സൂക്ഷിക്കുക (`python manage.py dumpdata`).
- **പ്ലാൻ മാറ്റങ്ങൾ:** സേവനദാതാക്കൾ സൗജന്യ പരിധി മാറ്റിയാലും പ്രോജക്റ്റിനെ ബാധിക്കാതിരിക്കാൻ സ്റ്റാൻഡേർഡ് Postgres ഉപയോഗിക്കുക.
- **സുരക്ഷ:** `SECRET_KEY`, API കീകൾ ഒരിക്കലും Git-ൽ പുഷ് ചെയ്യാതെ Environment variables ആയി മാത്രം സൂക്ഷിക്കുക (`.env`).
- **വേഗത:** സൗജന്യ Render സെർവർ ഉറക്കത്തിൽ നിന്ന് ഉണരാൻ 30-60 സെക്കൻഡ് എടുക്കും. ആപ്പിൽ നല്ലൊരു "ലോഡിങ് / സെർവർ കണക്റ്റിങ്" സ്ക്രീൻ നൽകുക.
