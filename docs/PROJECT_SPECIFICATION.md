# നാട്ടിലെ കമ്മ്യൂണിറ്റി ആപ്പ് – സമ്പൂർണ്ണ പ്രോജക്റ്റ് വിവരണം (Ente Naadu Specification)

> **വെബ്സൈറ്റ് + ആൻഡ്രോയിഡ് + iOS ആപ്പ് | അഡ്മിൻ, ഷോപ്പ്, യൂസർ മൊഡ്യൂളുകൾ | കുറഞ്ഞ ചെലവിൽ തുടങ്ങി ഭാവിയിൽ വളർത്താൻ**

---

## 1. പ്രോജക്റ്റ് എന്താണ്?

ഒരു നാട്ടിലെ ആളുകളെയും കടകളെയും അറിയിപ്പുകളെയും ഒരൊറ്റ പ്ലാറ്റ്ഫോമിൽ ബന്ധിപ്പിക്കുന്ന കമ്മ്യൂണിറ്റി ആപ്പ് ആണിത്. നാട്ടിൽ നടക്കുന്ന പരിപാടികളും അടിയന്തര അറിയിപ്പുകളും എല്ലാവരുടെയും ഫോണിൽ നോട്ടിഫിക്കേഷനായി എത്തും. നാട്ടുകാർക്ക് പരസ്പരം ചാറ്റ് ചെയ്യാനും വിളിക്കാനും അടുത്തുള്ള സുഹൃത്തുക്കളെ കാണാനും കഴിയും. നാട്ടിലെ ഹോട്ടലുകൾ, മെഡിക്കൽ ഷോപ്പുകൾ, ടെയ്‌ലറിംഗ്, ബാർബർ, അക്ഷയ തുടങ്ങിയ സ്ഥാപനങ്ങൾക്ക് തങ്ങളുടെ ഉൽപ്പന്നങ്ങളും സേവനങ്ങളും കാണിക്കാനും ഓർഡറും ബുക്കിംഗും സ്വീകരിക്കാനും ഇത് അവസരം നൽകും.

### ലക്ഷ്യങ്ങൾ:
- നാട്ടിലെ വിവരങ്ങൾ വേഗത്തിലും വിശ്വസനീയമായും എല്ലാവരിലും എത്തിക്കുക.
- പ്രാദേശിക കച്ചവടക്കാർക്ക് ചെലവില്ലാതെ ഓൺലൈൻ സാന്നിധ്യം നൽകുക.
- നാട്ടുകാർക്ക് ഒരിടത്ത് നിന്ന് കടകളും സേവനങ്ങളും കണ്ടെത്താൻ സൗകര്യം നൽകുക.
- പരാതികളും നിർദ്ദേശങ്ങളും നേരിട്ട് അഡ്മിനിലേക്ക് എത്തിക്കുക.
- തുടക്കത്തിൽ ചെലവ് ഏറ്റവും കുറച്ച്, ഉപയോഗം കൂടുന്നതനുസരിച്ച് വളർത്താൻ കഴിയുന്ന രീതിയിൽ നിർമ്മിക്കുക.

## 2. ഉപയോക്താക്കളും പ്ലാറ്റ്ഫോമുകളും

| മൊഡ്യൂൾ | ആര് | എവിടെ ഉപയോഗിക്കും |
| :--- | :--- | :--- |
| **അഡ്മിൻ** | പ്രോജക്റ്റ് നടത്തിപ്പുകാരൻ / വാർഡ് മെമ്പർ | വെബ് പാനൽ (കമ്പ്യൂട്ടർ / മൊബൈൽ ബ്രൗസർ) |
| **ഷോപ്പ്** | കടയുടമകൾ, ഹോട്ടലുകൾ, സേവന സ്ഥാപനങ്ങൾ | ആൻഡ്രോയിഡ്, iOS ആപ്പ് (വെബിലും) |
| **യൂസർ** | നാട്ടുകാർ | ആൻഡ്രോയിഡ്, iOS ആപ്പ് (വെബിലും) |

> **പ്രത്യേകത:** ഷോപ്പും യൂസറും ഒരേ മൊബൈൽ ആപ്പിൽ ആയിരിക്കും പ്രവർത്തിക്കുക. ലോഗിൻ ചെയ്യുമ്പോൾ അക്കൗണ്ടിൻ്റെ റോൾ അനുസരിച്ച് ശരിയായ സ്ക്രീനുകൾ ആപ്പിൽ കാണിക്കും. മൂന്ന് പ്ലാറ്റ്ഫോമുകളും ഒരേ ബാക്കെൻഡ് ഉപയോഗിക്കുന്നതിനാൽ ഡാറ്റ എല്ലായിടത്തും ഒന്നുതന്നെയായിരിക്കും.

## 3. അഡ്മിൻ മൊഡ്യൂൾ (Admin Module)

പ്ലാറ്റ്ഫോമിൻ്റെ പൂർണ്ണ നിയന്ത്രണം അഡ്മിനാണ്.

1. **ഡാഷ്ബോർഡ്:** ഉപയോക്താക്കൾ, ഷോപ്പുകൾ, ഓർഡറുകൾ, തീർപ്പാക്കാത്ത പരാതികൾ എന്നിവയുടെ തത്സമയ എണ്ണം.
2. **പരിപാടികളും അറിയിപ്പുകളും:** നാട്ടിലെ പരിപാടികൾ/ഫംഗ്ഷനുകൾ തലക്കെട്ട്, വിവരണം, തീയതി, സ്ഥലം, ഫോട്ടോ സഹിതം ചേർക്കുക; എല്ലാവർക്കും ഒരേസമയം നോട്ടിഫിക്കേഷൻ അയയ്ക്കുക; എഡിറ്റ്/ഡിലീറ്റ്.
3. **അടിയന്തര അറിയിപ്പുകൾ:** വൈദ്യുതി മുടക്കം, വെള്ളം, റോഡ് തടസ്സം, കാലാവസ്ഥാ മുന്നറിയിപ്പ് എന്നിവ ഉടനടി എല്ലാവർക്കും.
4. **ഷോപ്പ് മാനേജ്മെൻ്റ്:** പുതിയ കടകളുടെ രജിസ്ട്രേഷൻ പരിശോധിച്ച് അപ്രൂവ്/റിജക്റ്റ് ചെയ്യുക; "പരിശോധിച്ചത്" (Verified) ബാഡ്ജ് നൽകൽ.
5. **കാറ്റഗറി മാനേജ്മെൻ്റ്:** ഹോട്ടൽ, മെഡിക്കൽ, ടെയ്‌ലറിംഗ്, ബാർബർ, അക്ഷയ തുടങ്ങിയവ ചേർക്കുക; ഓരോന്നിനും ഇടപാട് രീതി (**ഓർഡർ / ബുക്കിംഗ് / റിക്വസ്റ്റ്**) നിശ്ചയിക്കുക.
6. **പരാതികളും നിർദ്ദേശങ്ങളും:** ഉപയോക്താക്കൾ അയച്ചവ വായിക്കുക, സ്റ്റാറ്റസ് (പുതിയത് / പരിശോധനയിൽ / പരിഹരിച്ചു) മാറ്റുക, ഔദ്യോഗിക മറുപടി നൽകുക.
7. **ബ്ലോക്ക് ചെയ്യൽ & സുരക്ഷ:** ഉപയോക്താവിനെതിരെയോ ഷോപ്പിനെതിരെയോ പരാതി വന്നാൽ പരിശോധിച്ച് ബ്ലോക്ക്/അൺബ്ലോക്ക് ചെയ്യുക; കാരണം രേഖപ്പെടുത്തണം; ബ്ലോക്ക് ചെയ്തവർക്ക് ലോഗിൻ, ചാറ്റ്, ഓർഡർ ഒന്നും സാധ്യമല്ല.
8. **ഉള്ളടക്ക നിയന്ത്രണം (Moderation):** റിപ്പോർട്ട് ചെയ്ത സന്ദേശങ്ങൾ, പരസ്യങ്ങൾ, റിവ്യൂകൾ എന്നിവ നീക്കം ചെയ്യുക.
9. **ഓഡിറ്റ് ലോഗ്:** ഓരോ ബ്ലോക്ക്/അപ്രൂവൽ ആര്, എപ്പോൾ, എന്തിന് ചെയ്തു എന്ന രേഖ.

## 4. ഷോപ്പ് മൊഡ്യൂൾ (Shop Module)

എല്ലാ കടകൾക്കും ഒരൊറ്റ പൊതു മൊഡ്യൂൾ; കാറ്റഗറി അനുസരിച്ച് ഇടപാട് രീതി മാറും.

### 4.1 ഇടപാട് രീതികൾ (Interaction Modes)

| രീതി | ഉദാഹരണം | യൂസർ ചെയ്യുന്നത് |
| :--- | :--- | :--- |
| **ഓർഡർ (Order)** | ഹോട്ടൽ ഭക്ഷണം, പലചരക്ക്, ബേക്കറി | ഐറ്റം തിരഞ്ഞെടുത്ത് ഓർഡർ അയയ്ക്കുന്നു |
| **ബുക്കിംഗ് (Booking)** | ബാർബർ, അക്ഷയ, ഹോട്ടൽ ടേബിൾ | തീയതിയും സമയ സ്ലോട്ടും തിരഞ്ഞെടുക്കുന്നു |
| **റിക്വസ്റ്റ് (Request)** | ടെയ്‌ലറിംഗ്, മെഡിക്കൽ ഷോപ്പ് | വിവരവും ഫോട്ടോയും സഹിതം അന്വേഷണം അയയ്ക്കുന്നു |

### 4.2 ഷോപ്പ് ഉടമയുടെ ഫംഗ്ഷനുകൾ
- **രജിസ്ട്രേഷൻ:** പേര്, കാറ്റഗറി, വിലാസം, ഫോൺ, മാപ്പിലെ സ്ഥാനം, സമയം, ഫോട്ടോകൾ (അഡ്മിൻ അപ്രൂവൽ വേണം).
- **ഉൽപ്പന്നം/മെനു/സേവനം ചേർക്കുക:** പേര്, ഫോട്ടോ, വിവരണം, വില, ലഭ്യത; സേവനങ്ങൾക്ക് സമയദൈർഘ്യം.
- **ഇടപാടുകൾ നിയന്ത്രിക്കൽ:** ഓർഡർ/ബുക്കിംഗ്/റിക്വസ്റ്റ് സ്വീകരിക്കുക അല്ലെങ്കിൽ നിരസിക്കുക; സ്റ്റാറ്റസ് മാറ്റുക (സ്വീകരിച്ചു → തയ്യാറാക്കുന്നു → തയ്യാർ/ഡെലിവർ ചെയ്തു); യൂസർക്ക് ഓരോ മാറ്റത്തിനും നോട്ടിഫിക്കേഷൻ.
- **"തുറന്നിരിക്കുന്നു / അടച്ചു" സ്വിച്ച്**, സ്റ്റോക്ക് തീർന്നത് ഒറ്റ ടാപ്പിൽ അടയാളപ്പെടുത്തൽ.
- **ഹോം ഡെലിവറി ഉണ്ടോ എന്നും ഡെലിവറി പരിധിയും സെറ്റ് ചെയ്യുക.**
- **ഇന്നത്തെ ഓഫർ / പ്രത്യേക വിഭവം** പോസ്റ്റ് ചെയ്യുക.
- **റിപ്പോർട്ടുകൾ & പങ്കിടൽ:** ആഴ്ചയിലെ ഓർഡർ/വിൽപ്പന റിപ്പോർട്ട് കാണുക; ഉൽപ്പന്നം WhatsApp-ൽ പങ്കിടുക.

### 4.3 കാറ്റഗറി തിരിച്ചുള്ള പ്രത്യേകതകൾ
- **ഹോട്ടൽ:** മെനു, ഭക്ഷണ ഓർഡർ, ടേബിൾ ബുക്കിംഗ്.
- **മെഡിക്കൽ ഷോപ്പ്:** മരുന്നിൻ്റെ പേരോ കുറിപ്പടി ഫോട്ടോയോ അയച്ച് അന്വേഷണം; കടയുടെ മറുപടി (ലഭ്യം/അല്ല). കുറിപ്പടി വേണ്ട മരുന്നുകൾ ആപ്പ് വഴി വിൽക്കുന്നില്ല, ഫാർമസിസ്റ്റ് പരിശോധിച്ച ശേഷം കടയിൽ നിന്ന് നേരിട്ട് നൽകണം.
- **ടെയ്‌ലറിംഗ്:** തുണിയുടെ തരം, അളവ്, ഡിസൈൻ ഫോട്ടോ, ഡെലിവറി തീയതി, പുരോഗതി സ്റ്റാറ്റസ്.
- **ബാർബർ:** സേവന ലിസ്റ്റ്, വില, സമയം ബുക്കിംഗ്.
- **അക്ഷയ:** സേവന പട്ടിക, ആവശ്യമായ രേഖകൾ, ടോക്കൺ/അപ്പോയിൻ്റ്മെൻ്റ്.

## 5. യൂസർ മൊഡ്യൂൾ (User Module)

- **രജിസ്ട്രേഷൻ/ലോഗിൻ:** തുടക്കത്തിൽ ഫോൺ നമ്പറും പാസ്‌വേഡും (SMS OTP പണച്ചെലവുള്ളതിനാൽ പിന്നീട് ചേർക്കാം); പ്രൊഫൈലും ഫോട്ടോയും.
- **അറിയിപ്പുകൾ:** പരിപാടികൾ, അടിയന്തര അറിയിപ്പുകൾ, ഓർഡർ സ്റ്റാറ്റസ്; പരിപാടികൾക്ക് "വരുന്നു / വരുന്നില്ല" (RSVP).
- **ഷോപ്പിംഗ്:** കാറ്റഗറി അനുസരിച്ച് കടകൾ കാണുക (അടുത്തുള്ളത് ആദ്യം), ഉൽപ്പന്ന ഫോട്ടോയും വിവരണവും വിലയും മെനുവും കാണുക, ഓർഡർ/ബുക്കിംഗ്/റിക്വസ്റ്റ് അയയ്ക്കുക, ഓർഡർ ട്രാക്ക് ചെയ്യുക, പഴയ ഓർഡറുകൾ കാണുക, കടയ്ക്ക് റിവ്യൂ നൽകുക, "വിളിക്കുക" ബട്ടൺ വഴി നേരിട്ട് വിളിക്കുക.
- **ഫ്രണ്ട്സ് (രണ്ടാം/മൂന്നാം ഘട്ടം):** ഫ്രണ്ട് റിക്വസ്റ്റ്, ചാറ്റ്, ഫോട്ടോ അയയ്ക്കൽ, ആപ്പിനകത്ത് വോയ്സ്/വീഡിയോ കോൾ.
- **GPS (നാലാം ഘട്ടം):** ലൊക്കേഷൻ പങ്കിടൽ ഓൺ ചെയ്താൽ അടുത്തുള്ള സുഹൃത്തുക്കളെ കാണാനും സന്ദേശം അയയ്ക്കാനും കഴിയും. ഡിഫോൾട്ട് ഓഫ്, സുഹൃത്തുക്കൾക്ക് മാത്രം, ഏകദേശ ദൂരം മാത്രം, ഏത് സമയത്തും ഓഫ് ചെയ്യാം.
- **പരാതിയും നിർദ്ദേശവും:** ഉപയോക്താവ്, ഷോപ്പ്, പൊതു പ്രശ്നങ്ങൾ എന്നിവയെക്കുറിച്ച് അയയ്ക്കുക; മറുപടി വരുമ്പോൾ നോട്ടിഫിക്കേഷൻ.
- **സുരക്ഷ:** മറ്റൊരാളെ റിപ്പോർട്ട് ചെയ്യുക, ബ്ലോക്ക് ചെയ്യുക.

## 6. നാടിനായുള്ള പൊതു ഫീച്ചറുകൾ (Community Features)

1. **അടിയന്തര അറിയിപ്പുകൾ:** വൈദ്യുതി, വെള്ളം, റോഡ്, കാലാവസ്ഥ എന്നിവയുടെ അറിയിപ്പ് അഡ്മിന് ഒറ്റ ടാപ്പിൽ എല്ലാവർക്കും അയയ്ക്കാം.
2. **പ്രാദേശിക സേവന ഡയറക്ടറി:** ഇലക്ട്രീഷ്യൻ, പ്ലംബർ, ഓട്ടോ/ടാക്സി, ഡോക്ടർമാർ, ആംബുലൻസ്, പഞ്ചായത്ത്/വില്ലേജ് ഓഫീസ് നമ്പറുകൾ; ഒരു ടാപ്പിൽ വിളിക്കാം.
3. **രക്തദാതാക്കളുടെ പട്ടിക:** സ്വമേധയാ ചേരുന്നവർ, രക്തഗ്രൂപ്പ് അനുസരിച്ച് തിരയൽ, അത്യാവശ്യത്തിന് നോട്ടിഫിക്കേഷൻ.
4. **ബസ് സമയം, ചന്ത/മാർക്കറ്റ് ദിവസങ്ങൾ.**
5. **വാടക / വിൽപന / ജോലി ഒഴിവ് ബോർഡ്:** അഡ്മിൻ അനുമതിയോടെ നാട്ടുകാർക്ക് പരസ്പരം പരസ്യം ചെയ്യാം.
6. **സംഭാവന / ധനസഹായ അറിയിപ്പുകൾ:** അഡ്മിൻ പരിശോധിച്ച ശേഷം മാത്രം.
7. **വെരിഫൈഡ് റിവ്യൂകൾ:** ഓർഡർ പൂർത്തിയായവർക്ക് മാത്രം കടയ്ക്ക് റേറ്റിംഗ് നൽകാം; വ്യാജ റിവ്യൂകൾ തടയാൻ കഴിയും.

## 7. ടെക്നോളജിയും ഘടനയും (Technology & Architecture)

- **ബാക്കെൻഡ്:** Django + Django REST Framework (`/api/v1/`)
- **ഡാറ്റാബേസ്:** PostgreSQL (Neon Serverless)
- **മൊബൈൽ ആപ്പ്:** Flutter (Android + iOS സിംഗിൾ കോഡ്ബേസ്)
- **വെബ്സൈറ്റ്/അഡ്മിൻ:** Django templates & Django admin
- **റിയൽടൈം ചാറ്റ്:** Django Channels / Firebase Firestore
- **നോട്ടിഫിക്കേഷൻ:** Firebase Cloud Messaging (FCM)
- **കോളിംഗ്:** Agora (മാസം 10,000 മിനിറ്റ് സൗജന്യം)
- **മാപ്പിംഗ്:** OpenStreetMap + flutter_map
- **ഫോട്ടോ സ്റ്റോറേജ്:** Supabase Storage / Cloudinary
- **ഹോസ്റ്റിംഗ്:** Render Free Web Service

### ഘടനാ തത്വങ്ങൾ:
1. ആപ്പും വെബ്സൈറ്റും ബാക്കെൻഡുമായി REST API (`/api/v1/`) വഴി മാത്രം ആശയവിനിമയം നടത്തുക.
2. Django ആപ്പുകൾ വേർതിരിക്കുക: `accounts`, `shops`, `orders`, `events`, `complaints`, `directory`.
3. കാറ്റഗറികൾ ഡാറ്റാബേസിൽ സൂക്ഷിക്കുക; പുതിയ തരം കട കോഡ് മാറ്റാതെ ചേർക്കാം.
4. എല്ലാ പ്രധാന മോഡലുകളിലും **"പ്രദേശം" (Area)** ഫീൽഡ്: ഭാവിയിൽ മറ്റ് നാടുകളിലേക്കും പഞ്ചായത്തുകളിലേക്കും എളുപ്പത്തിൽ വ്യാപിപ്പിക്കാം.
5. രഹസ്യ കീകൾ Environment variables-ൽ മാത്രം സൂക്ഷിക്കുക.

## 9. സുരക്ഷയും നിയമവും (Security & Compliance)

- **ഡാറ്റാ സംരക്ഷണം:** HTTPS, ഹാഷ് ചെയ്ത പാസ്‌വേഡുകൾ, ഇൻപുട്ട് വാലിഡേഷൻ, ആഴ്ചതോറും ബാക്കപ്പ് (`dumpdata`).
- **സ്വകാര്യത (Privacy):** ഇന്ത്യയിലെ DPDP നിയമങ്ങളും സ്റ്റോർ നയങ്ങളും പാലിച്ച് ലളിതമായ മലയാളത്തിൽ സ്വകാര്യതാ നയം. ഫോൺ നമ്പറും ലൊക്കേഷനും എടുക്കുന്നതിന് മുൻപ് അനുമതി.
- **മെഡിക്കൽ ഷോപ്പ് നിബന്ധന:** കുറിപ്പടി ആവശ്യമുള്ള മരുന്നുകൾ ആപ്പ് വഴി നേരിട്ട് പണം വാങ്ങി വിൽക്കില്ല; അന്വേഷണമായി മാത്രം അയക്കുകയും അംഗീകൃത ഫാർമസിസ്റ്റ് പരിശോധിച്ച ശേഷം നേരിട്ട് കടയിൽ നിന്ന് നൽകുകയും ചെയ്യുക.
- **വ്യാജ അക്കൗണ്ടുകൾ തടയൽ:** അഡ്മിൻ പരിശോധിച്ച കടകൾക്ക് മാത്രം "പരിശോധിച്ചത്" (Verified) ബാഡ്ജ്.
